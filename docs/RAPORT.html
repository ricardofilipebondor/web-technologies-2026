eSC — Chess Club Manager

Raport cerinte functionale · Tehnologii Web · UAIC

1. Introducere

Aplicația eSC gestionează activitățile unui club de șah: membri, antrenori, săli, competiții, premii și deplasări ale echipei reprezentative. Arhitectura este separată în trei straturi: frontend (HTML + fetch), backend API (PHP REST), database (SQLite + PDO).

2. Cerințe funcționale

2.1 Antrenori și colaboratori

  • CRUD antrenori via API /coaches
  • Înregistrare specializare, disponibilitate, rol (antrenor/colaborator)
  • Asociere la grupe (groups.coach_id) și activități (activities.coach_id)

2.2 Membri club

  • Înregistrare categorii: junior, senior, amator, profesionist
  • Date personale, rating, istoric participări și premii pe profil
  • Asociere antrenor și grupuri
  • Import/export CSV, JSON, XML (/members/export, /members/import-file)

2.3 Săli și activități

  • Săli: capacitate, dotări, intervale orare (hall_slots)
  • Programare antrenamente, cursuri, workshop-uri, simulane
  • Verificare conflicte sală și antrenor la programare

2.4 Competiții

  • Competiții locale/internaționale, online/fizic
  • Înregistrare participanți și rezultate
  • Clasamente și rapoarte cu export CSV/JSON/XML

2.5 Premii și performanțe

  • Premii asociate membrilor și competițiilor
  • Istoric individual (profil membru) și echipă (team_results)

2.6 Deplasări echipă reprezentativă

  • Înregistrare deplasări: destinație, date, scop
  • Cheltuieli: transport, cazare, masă
  • Raport decont per deplasare (CSV/PDF)

4. Model date

18 entități relaționale: users, roles, coaches, members, groups, halls, hall_slots, activities, competitions, participations, prizes, teams, team_results, trips, expenses și tabele de legătură M:N.

Proveniența datelor: introduse manual prin interfață, import fișiere, sau date demo din install.php.

5. Interacțiune utilizator

Autentificare → dashboard cu statistici → navigare modulară din sidebar. Fiecare modul oferă listare, filtrare, formulare CRUD și export unde este cazul. Rolurile (administrator, antrenor, responsabil financiar) controlează accesul la module.
